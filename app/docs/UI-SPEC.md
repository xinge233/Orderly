# 归序 Orderly · 界面规范

> 程序根目录为 `app/`。本规范只定义框架与模块之间的界面边界，不提供实现代码。

## 1. 不可变接口

以下四个插槽名从 S1 起冻结，不得改名、删除或改变语义：

```text
sidebar.item
plan.row
result.summary
settings.panel
```

新增插槽必须提交 RFC，并在本文件登记后才能使用。

## 2. 三主体布局

| 主体 | 职责 | 不负责 |
|---|---|---|
| 侧边栏 | 搜索、模块条目、拖拽排序、设置入口 | 执行状态 |
| 主界面 | 计划卡片、内容区、执行时间线 | 发起模块调用 |
| AI 对话栏 | 输入、计划预览、执行反馈 | 决定确认与撤销流程 |

侧边栏只渲染注册表提供的条目，不得写死任何模块名称。

AI 对话栏有两个状态：右下角收起胶囊、底部展开横条。默认收起，悬停展开。

设置界面为大弹窗，左侧为系统设置与功能设置分类，右侧为内容区。

## 3. 模块界面三键

模块 `ui` 对象只允许以下三键：

| 键 | 允许值 | 说明 |
|---|---|---|
| `icon` | 本文 §5 图标清单中的名称 | 框架用 CSS 或内联几何图形绘制 |
| `entry` | `sidebar.item` | 唯一允许的侧边栏入口插槽 |
| `accent` | `accent.primary` / `accent.secondary` | 只引用语义色名，不保存色值 |

危险与警告外观不接收模块配色。框架必须按 `risk` 推导。

## 4. 界面锚点

G8 检查以下六个稳定锚点：

| 锚点 | 对应界面 |
|---|---|
| `[data-o-anchor="sidebar"]` | 侧边栏 |
| `[data-o-anchor="workspace"]` | 主界面 |
| `[data-o-anchor="dock"]` | AI 对话栏 |
| `[data-o-anchor="settings-trigger"]` | 设置入口 |
| `[data-o-anchor="settings-dialog"]` | 设置弹窗 |
| `[data-o-anchor="theme-toggle"]` | 主题切换入口 |

这些锚点由框架维护，不属于模块扩展点。

## 5. 图标清单

S1 只允许以下图标名：

| 图标名 | 语义 |
|---|---|
| `archive` | 归档或收存 |
| `calendar` | 日程 |
| `file` | 单个文件 |
| `folder` | 文件夹 |
| `search` | 搜索 |
| `settings` | 设置 |
| `spark` | AI/计划入口 |
| `todo` | 待办 |

图标只能由 CSS 或内联几何图形绘制，不得引用外部资源、图标库或内联 SVG 数据。

## 6. 主题结构与语义变量

主题包是 JSON 数据，默认主题提供完整原始值，最小主题只覆盖两个原始色值。合并顺序固定：

```text
默认原始值 → 主题包覆盖 → 框架推导语义变量 → 写入页面变量
```

除 `web/themes/` 外，前端样式不得出现十六进制色值、`rgb()`、写死毫秒时长或字体名。

### 6.1 默认主题原始值

以下值定义默认主题的最低完整集合：

| 原始变量 | 默认值 |
|---|---|
| `--raw-primary` | `#2E6BE6` |
| `--raw-secondary` | `#6B7280` |
| `--raw-danger` | `#C2413B` |
| `--raw-warning` | `#B45309` |
| `--raw-page` | `#F5F7FB` |
| `--raw-card` | `#FFFFFF` |
| `--raw-text-primary` | `#172033` |
| `--raw-text-secondary` | `#5A6476` |
| `--raw-border` | `#D9DFE8` |
| `--raw-radius-card` | `20px` |
| `--raw-radius-control` | `12px` |
| `--raw-space-1` | `4px` |
| `--raw-space-2` | `8px` |
| `--raw-space-3` | `12px` |
| `--raw-space-4` | `16px` |
| `--raw-space-5` | `24px` |
| `--raw-space-6` | `32px` |
| `--raw-duration-fast` | `120ms` |
| `--raw-duration-base` | `220ms` |

最小主题只覆盖 `--raw-primary` 与 `--raw-secondary`，其余原始值必须由默认主题补齐。

### 6.2 语义变量最小集

默认主题必须为以下每个语义变量提供可解析值：

| 语义变量 | 用途 |
|---|---|
| `--accent-primary` | 主操作、选中态 |
| `--accent-secondary` | 次操作 |
| `--danger-action` | 删除类操作，任何主题下保持危险色相 |
| `--warning-action` | 写操作确认提示 |
| `--surface-page` | 页面底色 |
| `--surface-card` | 卡片底色 |
| `--text-primary` | 主要文字 |
| `--text-secondary` | 次要文字 |
| `--border-subtle` | 分隔线 |
| `--radius-card` | 卡片圆角，必须大于零 |
| `--radius-control` | 控件圆角 |
| `--space-1` | 最小间距 |
| `--space-2` | 次级间距 |
| `--space-3` | 常规小间距 |
| `--space-4` | 常规间距 |
| `--space-5` | 大间距 |
| `--space-6` | 最大间距 |
| `--duration-fast` | 快速反馈时长 |
| `--duration-base` | 常规过渡时长 |

主题切换只能改变页面变量并广播主题变更事件，不得替换样式文件，也不得给模块传递主题文件。

## 7. 动效三档

| 档位 | 内容 | 归属 |
|---|---|---|
| 系统级 | 页面切换、主题切换、设置弹窗开合 | 框架 |
| 反馈级 | 按钮反馈、条目选中、红点飞行 | 框架 |
| 内容级 | 卡片内部轻量效果 | 模块只能选用已登记效果，时长与曲线来自框架变量 |

AI 调用提示使用框架绘制的红点，从对话栏飞向对应侧边栏条目；目标不在视口时直接更新状态，并让侧边栏滚动到目标条目。

## 8. 降级与终态

以下情况必须直接呈现最终状态：

- 系统设置为“减少动效”；
- 首屏加载；
- 1 秒内快速重复触发；
- 目标元素不在视口。

界面必须先按最终状态渲染，动效只能叠加在已经可见且正确的内容上。禁止用初始透明或隐藏状态等待动画显示内容。

## 9. 设置控件

模块设置只支持三种控件：

| 控件 | 必需数据 |
|---|---|
| `number` | `default`、`min`、`max`、`step` |
| `toggle` | 布尔型 `default` |
| `select` | 字符串型 `default`、非空 `options` |

设置弹窗右侧必须同时存在三类控件实例。左侧分类必须包含“系统设置”和“功能设置”，可独立滚动。

## 10. 界面验收基线

- 1366×768 与 1920×1080 下三主体不重叠、不溢出、无横向滚动条。
- 侧边栏可搜索、可拖拽排序、可滚动。
- 设置弹窗可通过右上角关闭按钮和 `Esc` 关闭。
- 主题只改变量表换色，危险色继续表达危险语义。
- 减少动效时直接呈现终态。
- 空注册表显示空状态，不出现白屏或 `undefined`。
