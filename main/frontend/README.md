# Orderly 前端骨架

前端只使用 HTML、CSS 和原生 JavaScript 模块，不依赖 UI 框架或外部图标资源。

运行方式：

- 在 `main` 执行 `.\run.ps1`，然后打开 `http://127.0.0.1:8080/`。
- Maven 构建时会将本目录复制到 Spring Boot 的静态资源目录。

当前实现范围：

- 配置驱动的可滚动侧边栏与固定设置入口。
- 主显示区与完整视图生命周期：`render`、`mount`、`unmount`。
- 视图切换时先释放旧视图，并通过 AbortSignal 与清理回调释放异步资源。
- 可扩展的设置字段、三种主题和可替换动效策略。
- 模块目录固定 JSON 样例的校验及“契约 → 导航 → 已注册视图”转换。
- 动态模块文本统一通过 `textContent` 写入，不把后端或文件文本当 HTML。
- 仅作占位的 AI 输入栏。

当前不包含文件访问、任务执行、AI 调用、通知授权或任何后端写接口。

测试：

```powershell
npm test
```
