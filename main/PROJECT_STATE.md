## 本轮新增

### Java 控制层

- `backend/`：Spring Boot 3.4.12、Java 21、Maven 工程。
- `PlatformModule`：模块元数据契约。
- `ModuleHandler`：可选的受控命令处理契约。
- `ModuleRegistry`：模块发现、排序与重复 id 校验。
- `ModuleDispatchService`：未知模块/动作会被拒绝的最小编排层。
- `SampleTestModule`：只响应 `ping` 的无副作用空功能模块。
- `GET /api/platform/modules`：只读模块目录接口。
- 未开放任意命令执行、文件系统访问、AI 调用或任务状态写入接口。

### 前端

- `frontend/`：原生 HTML、CSS 和 JavaScript 模块。
- 配置驱动的可滚动侧边栏；设置入口固定在底部，不随导航滚动。
- 主显示区与视图注册表，已包含总览、通用占位和空功能试验台视图。
- 配置驱动的设置对话框，当前提供外观、语言和通知字段。
- 三种主题：纸页、夜航、苔原；主题通过 CSS 语义令牌切换。
- 可替换动效策略：灵动、克制、关闭。
- 底部固定 AI 指令输入栏；发送仅显示“尚未接入”反馈，不调用后端。
- 桌面与窄屏布局均有独立响应式规则。

### 启动入口

- `main/run.ps1`：使用工作区内 Maven 缓存启动应用。
- `main/run.ps1 -Test`：执行测试、打包并生成可运行 JAR。
