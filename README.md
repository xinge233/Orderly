# 归序 Orderly 交互原型

这是根据《归序 Orderly 项目策划书》和 UI 概念稿制作的前端交互原型。所有文件、待办、日程、执行进度与回滚结果均为模拟数据，不会访问或修改本机文件。

当前界面采用亮白偏粉、青蓝与柠檬黄点缀的未来感主题，主要使用渐变与阴影分层。任务启动和完成提示采用局部浮动弹窗，不再遮挡整个界面。

## 启动

```powershell
cd D:\code\服创赛\app
npm start
```

浏览器打开 `http://127.0.0.1:4173`。

## 可交互流程

- 输入自然语言目标并生成执行计划
- 修改、删除或添加计划步骤
- 模拟高风险删除的二次授权
- 启动任务并模拟执行进度
- 暂停、继续或中止任务
- 查看审计记录并执行整单回滚
- 在文件、待办、日程、回收站等页面之间切换
- 使用底部常驻大输入框随时与 AI 助手对话，回答自动收进“历史记录”
- 按全部、今天和本周筛选待办
- 使用顶部全屏按钮扩大工作区
- 使用“任务动效”临时按钮预览任务启动、风险确认、步骤推进、暂停、完成与回滚动画
- 顶部导航和底部 AI 输入栏固定在浏览器屏幕边界，页面内容独立滚动

## 保存草稿

每轮界面修改完成后运行：

```powershell
npm run draft -- "修改说明"
```

草稿会保存到 `drafts/时间戳/`，旧版本不会被覆盖。
