## 命令诊断：Add-Content 管道无效果

`Get-ChildItem -Path "C:\Users\lecoo\Desktop" -Filter *.txt | ForEach-Object { Get-Content $_.FullName | Add-Content -Path <dest> }` 无效果。

根因：桌面 5 个 .txt 全部 0 字节，`Get-Content` 返回空，追加空内容，命令本身完全正确且无报错。

此类故障模式值得记：**输入为空 + 零报错 = 用户无法察觉失败**。建议任何批量追加前先 `Where-Object { $_.Length -gt 0 }` 或用 `-ErrorAction`/计数确认。
